#1. Building spotify app


##########################################################################

Before building any backend project (like a Spotify-like API), you should first understand how a backend project is designed from scratch. This is the KT (knowledge transfer) mindset you should follow for every project.

Your goal in 2 days is not a full Spotify clone, but a clean backend system with:

User authentication
JWT security
Role-based access
PostgreSQL database
FastAPI APIs

Think of it like Spotify backend basics.

🧠 First Understand the Backend Architecture
Before writing code, always think in this order:

Client (Frontend / Postman)
        ↓
FastAPI Routes
        ↓
Service / Business Logic
        ↓
Database Layer
        ↓
PostgreSQL

Authentication flow:
User Login
   ↓
Verify Password (bcrypt)
   ↓
Generate JWT
   ↓
Send Token
   ↓
User uses token for APIs

Role-based flow:
JWT → extract role → check permission → allow / deny API

⚙️ Step 1 — Setup PostgreSQL using Docker

Run database first.
Example docker-compose:

version: "3"
services:
  postgres:
    image: postgres
    container_name: spotify_db
    environment:
      POSTGRES_USER: spotify
      POSTGRES_PASSWORD: spotify123
      POSTGRES_DB: spotify_db
    ports:
      - "5432:5432"

Run:
docker compose up -d

# psql -h localhost -U spotify -d spotify_db # password: spotify123

Now DB is ready.

⚙️ Step 2 — Create FastAPI Project

🔐 Step 4 — Password Hashing

Use bcrypt.

Flow:

User registers
   ↓
Password hashed
   ↓
Stored in database

Verification:

Login request
   ↓
Compare password with hash
   ↓
Allow login
🔑 Step 5 — JWT Authentication

When user logs in:

Server creates JWT:

payload = {
 "user_id": 1,
 "role": "admin",
 "exp": expiry_time
}

User sends token in API:

Authorization: Bearer <token>

Server verifies token before accessing route.

🛂 Step 6 — Role-Based Access

Example:

admin → upload songs
artist → upload own songs
listener → play songs

FastAPI dependency checks role.

Example logic:

if user.role != "admin":
    raise permission denied
